# Wyrmnail downloads

Builds of Wyrmnail, an open-world action RPG. Download them from the Distinct Arcade:
https://distinctpresence.com/arcade/#/play/wyrmnail

The files are attached to the latest release on this page.

## First launch

- Mac: unzip, then right-click the app and choose Open. macOS warns about apps from outside the App Store the first time.
- Windows: unzip, run Wyrmnail.exe, and if SmartScreen appears choose More info, then Run anyway.

## Requirements

- Mac: macOS 11 or later, Apple Silicon or Intel.
- Windows: Windows 10 or later, 64-bit, a graphics card with Vulkan support.

This repository holds the builds only. The game's source is not published.
